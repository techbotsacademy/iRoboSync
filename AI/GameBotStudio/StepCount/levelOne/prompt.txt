Create a simple step counter using a 30 pin ESP32 NodeMCU and an MPU6050.

Connect the MPU6050:

VCC → 3.3V
GND → GND
SCL → D18
SDA → D19

Write Arduino code that reads the MPU6050 movement using the library MPU6050 by Electronic Cats, 
detects footsteps, and counts the steps. Show the step count in the Serial Monitor.
