AI Elder Emergency Alert System
Complete Trainer Notes (Telegram + ESP32 + LittleFS + HTML)

Introduction
In this project, we will develop an AI Elder Emergency Alert System using an ESP32, Telegram Bot API, LittleFS, and an HTML-based user interface.
The ESP32 hosts a web page using LittleFS. When the user opens the webpage and speaks an emergency keyword such as "Help", the browser converts the voice into text and sends an emergency request to the ESP32. The ESP32 then activates the buzzer and LED and sends an emergency notification to Telegram.

LittleFS Explanation
What is LittleFS?
LittleFS (Little Flash File System) is a lightweight file system used to store files inside the ESP32's flash memory.
Why do we use LittleFS?
Instead of embedding large HTML, CSS, and JavaScript code directly into the Arduino sketch, LittleFS allows us to store these files separately in the data folder.
Advantages
Cleaner Arduino code. 
Easy to update web pages. 
Faster development. 
Better project organization. 
Supports multiple files (HTML, CSS, JavaScript, images, icons).
